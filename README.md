# 志布志市はいくつ？

ランダムに並んだ文字の中から **「志布志市」** を探して、いくつあるか当てるワードサーチ型ブラウザゲームです。

**遊ぶ →** https://shibushishi-ikutsu.vercel.app/

---

## ゲームの遊び方

1. 盤面サイズ（4×4〜20×20）を選んで「ゲーム開始」
2. ランダムに並んだ **志・布・市** の文字盤を目視で探索
3. 「志→布→志→市」の順に4文字が並んでいたら1個（8方向すべて対象）
4. 見つけた個数を入力して「回答する」
5. 回答後、正解箇所が矢印で表示されて答え合わせ

---

## 難易度

| 難易度 | サイズ | 特徴 |
|------|--------|------|
| 初級 | 4×4 〜 6×6 | 比較的見つけやすい |
| 中級 | 7×7 〜 10×10 | ある程度探す必要あり |
| 上級 | 11×11 〜 15×15 | かなり難しい |
| 超上級 | 16×16 〜 20×20 | 目視では非常に難しい |

---

## 探索ルール

- 対象文字列：`志 → 布 → 志 → 市`（4文字）
- 使用文字：`志` `布` `市` のみ（すべてランダム配置）
- 探索方向：右・左・下・上・右下・左上・右上・左下（8方向）
- 開始位置や方向が異なれば、同じマスを共有していても別カウント

---

## 機能

- 盤面サイズ選択（4×4〜20×20）
- 8方向の自動正解検出
- 回答後に正解箇所をSVG矢印でハイライト表示
- 再生成・リセット機能
- PC・スマホ両対応（レスポンシブ）

---

## 技術構成

HTML / CSS / JavaScript のみ（サーバー・フレームワーク不使用）

```
index.html   — UI構造
style.css    — スタイル
script.js    — ゲームロジック（盤面生成・探索・SVG描画）
```
